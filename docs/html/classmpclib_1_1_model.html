Detailed Description

Abstract base class for dynamic models used in model predictive control (MPC).

This class defines the common interface for all dynamic models used in the MPC library. Derived classes must define the dimensionality of the state and action vectors, as well as the dynamics functions for simulation and automatic differentiation.

The model also supports various types of constraints:

  • State constraints: Variable-wise lower and upper bounds on the state vector.
  • Action constraints: Variable-wise lower and upper bounds on the action vector.
  • General constraints: Arbitrary linear constraints on the state and/or action vectors.

virtual const Mat & mpclib::Model::general_constraints_action_matrix ( ) const
inlinevirtual

Get the general action constraints matrix.

The general action constraints matrix is a matrix of dimensions \( [\mathrm{Number\,of\,general\,constraints}, \mathrm{action\,size}] \). Each row of the matrix corresponds to a general constraint, and each column corresponds to an action variable. In HPIPM, this matrix is multiplied by the action vector at every timestep.

Returns
const Mat& - constant reference to the general action constraints matrix
