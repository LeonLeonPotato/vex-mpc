Detailed Description

Wrapper class of the Optimal Control Problem Quadratic Programming (OCP-QP) solver using HPIPM.

Author
Leon

This file defines the structures and methods for solving optimal control problems using the HPIPM library. It includes the definition of OCP parameters, the OCPQP class for managing the problem setup, and methods for relinearization, setting targets, and solving the problem.
