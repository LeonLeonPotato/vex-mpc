Detailed Description

Structure holding configuration parameters for the OCP solver.

Note
All matricies are expected to be in the correct shape. This means that all state cost (Q) matricies are of size (state_size, state_size), all action cost (R) matricies are of size (action_size, action_size), and all state-action correlation (S) matricies are of size (state_size, action_size).

enum class mpclib::OCPParams::WarmStartLevel
strong

Enum defining warm start levels.

Enumerator
NONE 

No warm start. Both state and input are "guessed" to be zero.

STATE 

Only the state is warm started. The input is "guessed" to be zero.

STATE_AND_INPUT 

Both state and input are warm started, i.e. reused from the previous solve.

FULL 

Full warm start, including state, input, other IPM variables.
