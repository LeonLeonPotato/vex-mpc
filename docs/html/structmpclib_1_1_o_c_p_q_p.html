Detailed Description

Class wrapping the OCP-QP solver.

Handles initialization and solution of OCP problems using HPIPM. Provides functions to set targets, initial conditions, constraints, and cost functions.

OCPQP::OCPQP ( const Model & model,
const OCPParams & ocp_params )

Construct a partially initialized QP wrapper.

All HPIPM structures are allocated and the static parts of the problem (dimensions, box constraints, state or action independent cost weights) are set up. No linearization or initial state setting is performed here – call one of the relinearize() overloads and set the initial state before solving.

Parameters
modelDynamics model
ocp_paramsHorizon length, cost weights and solver options.

◆ push_down_solution_actions()

void OCPQP::push_down_solution_actions ( )

"Push down" the solution action by one timestep.

This function helps hot start the solver by reusing the solution from the previous timestep. When hot start solving, the previous solution was solved at a previous world time. Thus, it makes sense that the solution at timestep \( i \) in current time should be close to the solution at timestep \( i-1 \) in the previous time.

Note
This function does not do anything to the action at timestep N-1

Relinearize the model dynamics from a sequence of states and actions.

Similar to relinearize, but this function will set the dynamics matricies at each timestep to the ones computed from the state and action pairs. Note that this differs from relinearize(Vec x, const std::vector<Vec>& u) in that it does not evolve any states.

Parameters
xStates to linearize around at each timestep.
uActions to linearize around at each timestep.
first_stage_dt_overrideOverride the time step for the first stage. If negative, the default time step from the model parameters is used.
See also
mpclib::Model::autodiff
Note
If the size of u or x is less than N, the last state & action will be used to fill the rest of the dynamics matricies. Additionally, if the size of x differs from u, the smaller of the two will be used.

◆ relinearize() [2/3]

void OCPQP::relinearize ( const Vec & x,
const Vec & u,
float first_stage_dt_override = -1.0f )

Relinearize the model dynamics using a single state and input.

This function will compute the jacobian of the model dynamics and set the linearized dynamics in the QP problem. This is used to approximate nonlinear models with a linear one - specifically, a first order taylor expansion, where \( f(x, u) \approx J_{x}x + J_{u}u + [f(x_{nom}, u_{nom}) - J_{x}x_{nom} - J_{u}u_{nom}] \)

Parameters
xState vector to linearize around.
uAction vector to linearize around.
first_stage_dt_overrideOverride the time step for the first stage. If negative, the default time step from the model parameters is used.
See also
mpclib::Model::autodiff

◆ relinearize() [3/3]

void OCPQP::relinearize ( Vec x,
const std::vector< Vec > & u,
float first_stage_dt_override = -1.0f )

Relinearize the model dynamics by evolving a state from a sequence of actions.

Similar to relinearize, but this function will evolve the state using the model dynamics mpclib::Model::infer and the sequence of actions. This essentially "predicts" the future states of the model, and moves the operating points to the predicted states each state. This prevents errors from linearization in highly non-linear models, when \( x \) is far from \( x_{nom} \), or when \( u \) is far from \( u_{nom} \).

Parameters
xthe initial state to evolve from.
ulist of actions to evolve the state with.
first_stage_dt_overrideOverride the time step for the first stage. If negative, the default time step from the model parameters is used.
See also
mpclib::Model::autodiff
Note
If the size of u is less than N, the last state & action will be used to fill the rest of the dynamics matricies.

Constrain the current state.

In HPIPM, the initial state is set as both the lower and upper bounds of the state variable. This constrains all future states, which are states in timesteps from \( [1, N] \) to evolve from the initial state.
