\doxysubsection{Detailed Description}
A model representing a differential drive robot. 

This class implements the dynamics of a differential drive system, such as a typical two-\/wheeled ground robot. It extends the \doxylink{classmpclib_1_1_drive_model}{Drive\+Model} base class and defines both the dynamics and constraints for the system.

The model supports general constraints on the individual wheel speeds (left and right), which are derived from the maximum allowed drivetrain speed. It does not impose box constraints on the state or action vectors directly.

The model parameters define physical properties such as drivetrain width, max wheel speed, and acceleration behavior.
