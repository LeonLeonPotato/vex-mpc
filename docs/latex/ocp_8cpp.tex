\doxysubsection{Detailed Description}
Wrapper class of the Optimal Control Problem Quadratic Programming (OCP-\/\+QP) solver using HPIPM. 

This file contains the implementation of the \doxylink{structmpclib_1_1_o_c_p_q_p}{OCPQP} class, which is responsible for setting up and solving optimal control problems using the HPIPM library. The implementation includes methods for setting up problem dimensions, constraints, costs, and relinearizing the dynamics. It also provides functionality for setting target states and solving the problem.

The \doxylink{structmpclib_1_1_o_c_p_q_p}{OCPQP} class leverages the HPIPM library to solve quadratic programming problems that arise in optimal control. The implementation includes helper functions for creating masks, indices, and bounds from constraints, as well as methods for relinearizing the system dynamics using automatic differentiation. The solver supports warm-\/starting and allows for customization of solver parameters such as iteration limits and accuracy levels.

Key features:\+
\begin{DoxyItemize}
\item Setup of problem dimensions, constraints, and costs.
\item Support for state, action, and general constraints.
\item Automatic differentiation for relinearization of dynamics.
\item Warm-\/starting and customizable solver parameters.
\item Debugging utilities for printing arrays and intermediate results.
\end{DoxyItemize}

Dependencies:\+
\begin{DoxyItemize}
\item HPIPM library for solving quadratic programming problems.
\item Eigen library for matrix and vector operations.
\item Autodiff library for automatic differentiation of nonlinear functions.
\end{DoxyItemize}

Usage:\+
\begin{DoxyItemize}
\item Instantiate the \doxylink{structmpclib_1_1_o_c_p_q_p}{OCPQP} class with a model and OCP parameters.
\item Use the provided methods to set up the problem, relinearize dynamics, and solve the problem.
\item Retrieve the solution and status using the appropriate methods.
\end{DoxyItemize}
