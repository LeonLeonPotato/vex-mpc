\doxysubsection{Detailed Description}
Class wrapping the OCP-\/\+QP solver. 

Handles initialization and solution of OCP problems using HPIPM. Provides functions to set targets, initial conditions, constraints, and cost functions.

"{}\+Push down"{} the solution state and actions by one timestep. 

This function helps hot start the solver by reusing the solution from the previous timestep. When hot start solving, the previous solution was solved at a previous world time. Thus, it makes sense that the solution at timestep $ i $ in current time should be close to the solution at timestep $ i-1 $ in the previous time.

\begin{DoxyNote}{Note}
This function does not do anything to the state at timestep N, and the action at timestep N-\/1.
